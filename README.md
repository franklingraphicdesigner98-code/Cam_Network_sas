# Cam Network Soluciones S.A.S.

Sitio web de Cam Network Soluciones S.A.S., construido con Vue 3 + Vite. El proyecto usa Vue 3 `<script setup>` SFCs, consulta la [documentación de script setup](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) para más detalles.

Más información sobre soporte de IDE para Vue en la [guía de Vue](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).
